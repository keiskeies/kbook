📁 项目结构

kbook/
├── frontend/          # React 前端应用
│   ├── src/
│   │   ├── pages/     # 页面组件（首页/阅读/书架/搜索/AI/社交/管理）
│   │   ├── components/# 通用组件（Reader/Navbar/BookCard...）
│   │   ├── stores/    # Zustand 状态管理
│   │   └── lib/       # 工具函数与 API 封装
│   └── public/        # PWA manifest 与静态资源
├── backend/           # Spring Boot 后端服务
│   └── src/main/java/com/kbook/
│       ├── controller/# REST API 控制器
│       ├── service/   # 业务逻辑（13 个 Service）
│       ├── entity/    # JPA 实体
│       ├── repository/# 数据访问层
│       ├── config/    # 配置类（安全/CORS/Redis/Qdrant/WebSocket）
│       └── dto/       # 数据传输对象
├── deploy/            # Docker Compose + Nginx 部署配置
├── config/            # 项目配置文件
└── index.html         # 项目介绍页（本页面）

🚀 快速开始

# 1️⃣ 前端
cd frontend
npm install
npm run dev          # → http://localhost:5173

# 2️⃣ 后端（需先启动 MySQL + Redis + Qdrant）
cd backend
mvn spring-boot:run # → http://localhost:8080

# 3️⃣ 全栈一键部署（Docker Compose）
cd deploy
docker compose up -d # → http://localhost
