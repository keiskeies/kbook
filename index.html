项目状态

前端 已就绪

React 19 + TypeScript + Vite + Tailwind + shadcn/ui

React Router 7 Zustand Axios PWA
后端 已就绪

Spring Boot 3 + MySQL + Redis + JWT

JPA Security Lettuce HikariCP

启动方式

# 前端
cd frontend
npm install
npm run dev     # http://localhost:5173

# 后端
cd backend
mvn spring-boot:run  # http://localhost:8080
