01

AI 图书问答

用户提问 → AI 搜索书中内容 → 结合风格回答

💬 图书问答 — 6 步完整流程

1
用户提问 + 选风格
4 种对话风格：随和(口语化) / 深度(结构化分析) / 简洁(≤200字) / 幽默(可吐槽可夸)。
4
向量检索 — RAG 多路召回
每个子查询 → Qdrant 检索 → 按前 80 字符去重(保留最高分) → 相邻片段合并(chunkIndex 差≤1) → 乱码检测(?>10% 丢弃)。
⚠️ 无结果 → forceReEmbed 重建向量重搜
✅ 每片段加"【参考片段N】"前缀，总量截断到 ragMaxChars
2
向量就绪检查 + 压缩摘要
确保书籍内容已向量化，同时懒生成 LLM 压缩摘要。
⚠️ 未嵌入 → 自动触发，每 2s 轮询，最多等 1 小时
✅ 摘要懒生成：首次提问时 LLM 生成，后续复用
5
流式输出 + 历史压缩
SSE 逐 token 推送，完成后持久化到 DB。
压缩算法：超 80% token 上限时逐条压缩，目标 ≤60%。每条 LLM 压缩到 200 字。
✅ 压缩失败不影响主流程 / SSE 超时自动取消 AI 任务
3
智能查询扩展
LLM 拆解为最多 9 个子查询(每个≤15字)：核心概念 + 相关主题 + 上下位概念。支持宏观(目录)和微观(概念钻取)两种模式。
⚠️ AI 扩展失败 → 回退原始关键词
6
组装消息 — 4 层提示词
System
角色风格 — 4种预设 + 外部 JSON 热加载
User#1
书籍信息 — 书名/作者/标签/评分/目录/压缩摘要(静态缓存)
User#2
对话历史 — 超 80% token 自动压缩到 60%
User#3
RAG + 问题 — 参考片段(≤100字引用) + 用户问题
02

圆桌派

多位 AI 角色围绕一本书讨论 — 每次一人发言

🎙️ 圆桌派 — 6 步完整流程

1
智能选角 — 3 层回退
选出 4-6 个嘉宾：① Redis 热度排序(7天滑动窗口) ② AI 画像匹配(用户兴趣+角色标签) ③ 随机标签兜底。
⚠️ LLM 失败 → 标签匹配 / 标签也失败 → 从前 20 随机选
✅ 主持人固定为 "主持人" 角色，始终参与
4
流式输出 — 角色发言
SSE 逐 token 推送，事件格式: data:[DONE] / event:roleKey / data:content。完成后保存到 DB。
✅ 主持人发言自动判断(是否需要引导话题)
2
角色专属搜索 + 外部知识
LLM 按角色专业领域生成搜索词(核心概念+延伸方向)→书内向量检索。同时生成 2-3 条外部知识补充。
⚠️ LLM 生成搜索词失败 → 回退"书名+角色关键词"
✅ 每条知识标注来源：SEARCH(书内) / EXTERNAL(补充)
5
覆盖追踪 + 历史压缩
3 层覆盖评估：① 目录级(章节覆盖) ② 大纲级(LLM 生成讨论要点) ③ 摘要级(书的 AI 摘要)。评级 S/A/B/C/D/F。
⚠️ 覆盖分析失败 → 不注入引导
✅ 主持人注入引导语："请围绕XX展开讨论"
3
组装消息 — 7 层提示词
L1
行为规则 — "必须制造冲突" + 角色行为指令
L2
书籍信息 — 书名/作者/标签/评分/目录/压缩摘要
L3
讨论历史 — 超 80% token 自动压缩到 60%
L4
角色设定 — 人设/金句/6参数(性格/语言/智慧/情感/互动/知识)
L5
书内搜索 — 步骤2的向量检索片段
L6
外部知识 — 步骤2的 2-3 条补充
L7
发言指令 — "请以XX身份发言" + 引导语
6
选下一位 — 4 层（与发言完全不同）
System
5级规则：①沉默者上场 ②禁连续 ③主持人控场 ④最少优先 ⑤最能接话
User#1
书籍+全部角色人设 — 含"社交直觉与张力"
User#2
加权历史 — 三级权重：焦点(100%)/近期(30%)/背景(10%)
User#3
公平约束 — 禁连续/沉默者优先/计数
⚠️ LLM 失败 → 回退：选发言最少的非连续角色
✅ → {"nextSpeaker":"PSYCHOLOGIST"} → 回到步骤3
03

奇葩说

正反方 4v4 辩论 — 5 轮不同规则

⚔️ 奇葩说 — 6 步完整流程

第1轮
开篇立论
正一→反一
第2轮
质询交锋
只能问/只能答
第3轮
反驳强化
逐条拆解
第4轮
自由辩论
全员抢麦
第5轮
总结陈词
反四→正四
1
选择轮次规则
5 轮固定流程：① 开篇立论(150-250字搭框架) ② 质询交锋(30-60字只问/只答，2 Q&A 对) ③ 反驳强化(120-180字逐条拆解) ④ 自由辩论(20-80字抢麦，每人可多次) ⑤ 总结陈词(200-350字升华)。
✅ OPENING→CROSS_EXAM→REBUTTAL→FREE→CLOSING 状态机
4
流式输出 + 7维评分
SSE 逐 token 推送。完成后 7 维评分：逻辑性/说服力/反驳力/感染力/知识运用/幽默感/整体印象。
✅ 主持人点评 → 角色评论 → 评委打分
2
生成领域知识
LLM 为每位辩手按专业领域生成 3-5 条论证素材(观点+论据+引用方向)。
⚠️ 生成失败 → 不注入外部知识，辩手纯靠设定发挥
5
推进轮次 + 辩论报告
状态机自动推进：OPENING→CROSS_EXAM→REBUTTAL→FREE→CLOSING。5 轮结束后 LLM 生成 Markdown 报告。
报告结构：概要 / 精彩回顾 / 评分表格 / 正反分析 / 逻辑漏洞 / 评审结语
3
组装消息 — 5 层提示词
L1
轮次规则 — 6种模板：开篇/质询提问/质询回答/反驳/自由辩论/总结，各有不同字数及输出格式要求
L2
辩题+立场+知识 — 辩题描述、正方/反方立场、步骤2生成的领域论证素材
L3
历史+上下文 — 本轮及之前所有发言记录、当前辩论阶段和轮次信息
L4
角色+输出要求 — 辩手人设/性格参数/说话风格 + 当前轮次的具体输出指令
L5
书内检索片段 — 向量检索的原文内容（可选，增强论证依据）
6
选下一位 — 仅自由辩论轮（其他轮固定顺序）
System
5条规则：①选发言少的 ②正反交替 ③不选上一位 ④考虑走向 ⑤冷落者优先
User
辩题+立场+发言次数+上一位
⚠️ 选了同方 → 强制切换 / LLM失败 → 选对方最少者

✨ 三个核心设计

🔄

热加载

角色配置修改后，调用一个接口即可生效，无需重启服务
🧠

分层提示词

不变的内容放前面（书籍信息），变化的放后面（RAG、指令），利用缓存加速
🎭

角色化 AI

56+ 个 AI 角色，每个有独立人设、说话风格、搜索关键词和性格参数

智能调度
